# UK Content AI

First-stage shell for a personal AI content creation agent.

## Planned workflow

1. Chat with the agent.
2. ChatGPT acts as the reasoning/orchestration layer.
3. Research current UK news/trends.
4. Decide whether the request needs an image or video.
5. Generate the visual.
6. Edit/assemble the final media.
7. Save the final file.
8. Return caption and hashtags separately.

## Important

API keys should never be placed directly in `index.html` or client-side JavaScript. The next stage should add a secure backend/API layer.

## Current stage

The UI is functional, but the AI/tool connections are intentionally not connected yet.
